# Elm-Astro YouTube Embed

This project demonstrates how to integrate an Elm component into an Astro project to embed a YouTube video using an iframe. The Elm module creates a responsive YouTube embed, and Astro is used as the static site generator.

## Project Structure
├── public │ ├── elm.js # Generated by compiling the Elm code │ 
└── index.html # HTML entry point that embeds the Elm component ├── src │ 
└── YouTubeEmbed.elm # Elm module that returns an iframe view ├── package.json 


## Prerequisites

- **Node.js** & **npm** – [Download from Node.js](https://nodejs.org/)
- **Elm** – [Download Elm](https://elm-lang.org/)
- **Astro** – This project uses Astro for static site generation. You can create and run an Astro project by following [Astro's Getting Started](https://docs.astro.build/en/getting-started/).

## Setup Instructions

### 1. Clone the Repository

Clone this repo to your local machine and navigate into the project directory:


git clone <repository-url>
cd <repository-directory>

### 2. Install Dependencies
Install the required npm packages:

npm install

### 3. Install Elm packages
Make sure the bellroy/elm-embed-youtube package is installed (if needed):

For Elm 0.18, run:

elm-package install bellroy/elm-embed-youtube
For Elm 0.19, run:

### 4. Build Elm Ccomponent
Compile your Elm module to generate the JavaScript file:

elm-make src/YouTubeEmbed.elm --output=public/elm.js

This command creates elm.js in the public folder which is loaded by your HTML file.

### Run Astro project

npm run dev

Or Alternatively if you have used index.html as your UI to interact with Elm components. You can run this commmand below;

live-server public
